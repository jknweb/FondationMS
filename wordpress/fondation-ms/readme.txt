Thème institutionnel de la Fondation MS, entièrement administrable depuis le tableau de bord.

== Description ==

Page d'accueil composée de sections modifiables : bannière avec encadré « La une »,
chiffres clés, présentation et mot du fondateur, domaines d'intervention, projets phares,
fil d'actualité, galerie photo et programme radio, appel à l'engagement, diaporama.

Aucune extension requise. Voir GUIDE-UTILISATION.md pour la prise en main.

== Installation ==

1. Apparence › Thèmes › Ajouter › Téléverser le fichier fondation-ms.zip, puis Activer.
2. Menu « Fondation MS » › Importer le contenu de départ.
3. Réglages › Général : fuseau horaire Kinshasa ; Réglages › Permaliens : Enregistrer.
